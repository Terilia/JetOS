NYINAH CORP · HUD COLOR THEME

Configuration → HUD Theme · runs the same horizon + radar code with each palette
Themes are stored as hud_theme = 0..3 in CustomData. Cached once per tick by HUDModule.CacheTheme(), then read via HUD_PRIMARY, HUD_SECONDARY, HUD_HORIZON, HUD_RADAR_FRIENDLY properties so renderers don't pay a config lookup per call. Colors below come straight out of HUDModule.cs:17-20.
