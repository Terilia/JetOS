| `"StopSound"` | IMySoundBlock | Diagnostics only |

terminal action factory, so they don't appear as string literals in decompiled DLLs.

## Type Widening Notes

- `MyDetectedEntityInfo.Velocity` is `Vector3` (single precision), but we store as `Vector3D`.
  Implicit conversion `Vector3 → Vector3D` is safe (no precision loss in float→double direction).
- `MoveIndicator` is `Vector3`, same treatment.
- `SelectedAttackPattern` is `long`, we assign `3` (int → long implicit). Fine.
